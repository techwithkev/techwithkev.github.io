In supervised learning, a teacher provides the right answer for every example. In unsupervised learning, there are no labels at all. In RL, an agent learns by interacting with an environment and receiving reward signals - feedback that says "that was good" or "that was bad" - but without being told exactly what the right action was.This is how humans and animals learn many skills: a child learns to walk not by being given a textbook of walking mechanics but by trying, falling, and noticing that staying upright feels better. An RL agent does the same thing, but in a formal mathematical framework.?? Class 10 connection: In Class 10, students learned that search algorithms (A*, BFS) find optimal paths through a state space by planning ahead. RL also works with state spaces, but instead of planning with a known map, the agent discovers the map by exploring - it does not know the rules of the environment in advance.1.2  An Everyday Analogy - The Video Game AnalogyImagine a child playing a video game for the first time with no instructions. The child is the agent. The game is the environment. At each moment, the screen shows the current state (the child's position, enemies, score). The child chooses an action (move left, jump, shoot). The game responds with a new state and a reward signal (score goes up = positive reward; character dies = negative reward). Over time, the child discovers which actions in which states lead to high total score.Every element of RL has a direct counterpart: State = screen image. Action = button press. Reward = score change. Environment = game engine. Agent = player. Policy = the child's strategy (e.g. "always jump when I see a gap"). The agent's goal is to find the policy that maximizes total reward over time.?? Key Insight: RL is not told the right answer - it discovers what is good by trying. The reward signal is delayed and sparse: a chess player only learns whether a move was good when the game ends many moves later. The Bellman equation is the mathematical trick that propagates this delayed reward backward through time.?? Classroom tip: Before introducing any math, ask students: "Has anyone trained a pet? How did you do it?" They will describe positive reinforcement - treat when the pet does the right thing. Connect: RL is exactly this, formalized. The mathematical framework makes it work for agents that must choose among thousands of actions in thousands of states.PropertyReinforcement LearningSupervised LearningTraining signalReward from environment (sparse, delayed)Label for every example (dense, immediate)GoalMaximize cumulative reward over timeMinimize prediction error on labelled dataKnows right answer?No - must discover it by exploringYes - provided by the datasetCourse examplesMDP, Q-learning, ?-greedy bandit (Class 13)Logistic regression, decision trees (Classes 5Ð6)AnalogyChild playing a video gameChild being tutored with a textbook and answer keyPart 2 - Markov Decision Processes (MDPs)2.1  The Big IdeaA Markov Decision Process is the formal mathematical model for the RL problem. It defines the environment precisely enough that an agent can reason about which actions to take. An MDP has five components, each with a specific role.Step 1: Define the state space S - every possible situation the agent could be in. Step 2: Define the action space A - every possible action the agent can take. Step 3: Define the transition function P(s'|s,a) - given the current state s and action a, what is the probability of landing in state s'? Step 4: Define the reward function R(s,a) - the immediate reward received after taking action a in state s. Step 5: Add a discount factor ? (gamma) - a number between 0 and 1 that controls how much the agent values future rewards compared to immediate rewards.?? Key Insight: The Markov property means the future depends only on the current state - not on the history of how we got here. This is the assumption that makes RL mathematically tractable. If the future depended on all past states, the state space would be impossibly large.2.2  The Discount Factor ?The discount factor ? A reward received k steps in the future is worth ?? times a reward received now.Intuition: £100 available today is worth more than £100 promised in ten years - because of uncertainty and opportunity cost. RL encodes this same preference mathematically.# Effect of different gamma values# ? = 0: agent only cares about immediate reward# ? greedy short-sighted behavior# ? good for environments where delayed reward is not important# ? = 1: agent values future rewards equally to present rewards# ? far-sighted behavior# ? can cause problems if episode never ends (sum diverges)# ? = 0.9 (typical): reward k steps away is worth 0.9^k ? It is the mathematical backbone of Q-learning and every RL algorithm.State-value function: V(s) = maximum expected total discounted reward starting from state s.Bellman equation: V(s) = R(s,a*) + ? ? V(s')In plain English: the value of being in state s equals the immediate reward from taking the best action, plus the discounted value of the next state. This equation is recursive - V(s) is defined in terms of V(s'). RL algorithms solve for V(s) by iterating until the values stop changing.Full Bellman worked example:State A: immediately rewards +2, transitions to state BState B: immediately rewards +10, transitions to terminal state (value = 0)Discount factor: ? = 0.9V(B) = 10 + 0.9 ? 0 = 10.0V(A) = 2 + 0.9 ? V(B) = 2 + 0.9 ? 10 = 2 + 9 = 11.0Interpretation: being in state A is worth 11 points total becauseyou get 2 now and a discounted 9 from state B.Exam answer: Always compute the terminal state value first, thenwork backwards. Q-values are more useful than V-values because they tell the agent not just how good a state is, but which specific action to take.The Q-learning update rule (shown conceptually): Q(s,a) ? Q(s,a) + ? ? [R + ? ? max(Q(s',a')) ? Q(s,a)]. The term in brackets is the TD error (Temporal Difference error) - the difference between what the agent expected and what it actually received. ? (alpha) is the learning rate, controlling how fast the agent updates its beliefs.Part 3 - Exploration vs Exploitation3.1  The Core TensionThe exploration-exploitation tradeoff is one of the most important conceptual challenges in RL. Exploitation means choosing the action the agent currently believes is best. Exploration means trying actions that might be better, but whose value is unknown.An agent that only exploits (greedy) gets stuck at the first good strategy it finds. It never discovers whether a different action might lead to much higher rewards. An agent that only explores (purely random) never uses what it has already learned. The optimal strategy balances both.?? Key Insight: The multi-armed bandit problem makes the tradeoff concrete. Imagine a row of slot machines (bandits). You do not know which machine pays out most. Exploitation: keep playing the machine that has paid out most so far. Exploration: occasionally try other machines in case one of them is secretly better. ?-greedy is the simplest policy that balances both.3.2  The ?-Greedy Policy?-greedy (epsilon-greedy) is the standard solution to the exploration-exploitation tradeoff. It learns Q-values directly from experience.The algorithm: Step 1 - Initialize all Q(s,a) = 0. Step 2 - Observe current state s. Step 3 - Choose action a using ?-greedy. Step 4 - Take action a, receive reward R, observe new state s'. Step 5 - Update: Q(s,a) ? Q(s,a) + ? ? [R + ? ? max_a'(Q(s',a')) ? Q(s,a)]. Step 6 - Set s = s'. Step 7 - Repeat from Step 2.?? Key Insight: Q-learning is guaranteed to converge to the optimal Q-values if every state-action pair is visited infinitely often and the learning rate ? satisfies certain conditions. In practice, finite training with ?-greedy exploration approximates this well enough for many tasks.4.2  What Each Term in the Update Rule MeansQ(s,a) - the current estimate of how good it is to take action a in state s.? - learning rate. Controls how much the new information overrides the old estimate. ? = 1 means complete override. ? = 0.01 means very slow update.R - the immediate reward received after taking action a in state s.? ? max_a'(Q(s',a')) - the discounted estimate of the best possible future value from the new state s'. This is the "bootstrap" - using the current estimate of future value to update the current Q-value.[R + ? ? max_a'(Q(s',a')) ? Q(s,a)] - the TD error. Positive means reality was better than expected (update Q upward). Negative means reality was worse than expected (update Q downward).4.3  Connecting to the ?-Greedy Bandit NotebookThe Class 13 notebook implements a multi-armed bandit - the simplest RL problem. In RL, the agent only gets a reward signal that says 'good' or 'bad', and only sometimes. It has to figure out which action caused the good outcome.""Q-learning needs to know the environment's rules""That's the key insight - Q-learning is model-free. It never uses P(s'|s,a). It figures everything out by actually trying actions and seeing what happens.""Making gamma very high means the agent explores more""Gamma and epsilon do different things. Gamma controls how patient the agent is about future rewards. Epsilon controls how often it tries random actions. They are independent.""The Bellman equation gives you the best action""The Bellman equation gives you the value V(s) of a state. To get the best action, you compare Q(s,a) for each possible action and pick the highest. Value and action are separate.""If epsilon is zero the model learns faster""An epsilon of zero means pure exploitation - the agent never explores. It gets stuck with its first strategy and never discovers better options. You need some exploration.""Return and reward are the same""Reward is the single number you get right now. Return is the sum of all future rewards, discounted by gamma. If you get +1 reward for 10 steps with gamma=0.9, the return from step 1 is much more than 10."7.3  The Key Numbers to Know ColdNumber / FormulaWhat it isWhy it matters? (gamma) ?
