You're the Algorithm Engineer

Real recommendation systems follow decision logic — IF the user likes X, THEN suggest Y. Your task: design this logic for a board game recommender using a top-to-bottom flowchart.

  • 📥 Inputs — What questions should the recommender ask? (Number of players? Favourite genre? Play time?)
  • 🔀 Decision Rules — Connect from TOP port (input) into side ports: LEFT for YES, RIGHT for NO.
  • 📤 Output — The final game suggestion at the bottom of each path.
