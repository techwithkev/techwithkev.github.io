Data Types — Quick Reference

Use this cheatsheet to classify the data collected by your apps:

🔢 Numerical Data

Age, watch time, temperature, scores, prices, location coordinates

🏷️ Categorical Data

Genre preferences, Yes/No settings, country, language, device type

📝 Textual Data

Posts, search queries, reviews, captions, comments, direct messages

📸 Visual Data

Photos, facial scans, video uploads, screenshots, camera feed

🎙️ Auditory Data

Voice messages, speech-to-text audio, music clips, background mic listening
