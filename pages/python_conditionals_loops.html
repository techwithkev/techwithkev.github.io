Quick Reference - When to use what

if
One condition, act or skip
if-else
Exactly two paths: do X or Y
if-elif-else
3+ mutually exclusive cases
for loop
Known collection or fixed count
while loop
Repeat until a condition flips

Ex 16Fix the Bug1 pt

This code should print each item in cart along with its index (e.g. 0 apple, 1 banana…). It runs, but the output is wrong. What is the bug?

# Intended output: 0 apple   1 banana   2 mango
cart = ["apple", "banana", "mango"]
for i in range(len(cart)):
    print(i, cart[i + 1])
  • A) range(len(cart)) should be range(1, len(cart))
  • B) cart[i + 1] should be cart[i] - the + 1 shifts every item by one index
  • C) print(i, cart[i + 1]) should use print(i + 1, cart[i])
  • D) The loop needs an if condition to check the index
Ex 17Fix the Bug1 pt

This code is supposed to print “Even” or “Odd” for numbers 1 to 5. Instead it prints nothing at all. What is the bug?

# Should print Even or Odd for 1, 2, 3, 4, 5
for n in range(1, 6):
    if n % 2 = 0:
        print(n, "Even")
    else:
        print(n, "Odd")
  • A) range(1, 6) should be range(1, 5) to include 5
  • B) n % 2 = 0 should be n % 2 == 0 - one = is assignment, not comparison
  • C) The else block should be elif n % 2 != 0
  • D) n % 2 should be n / 2
Ex 18Fix the Bug1 pt

This while loop is supposed to halve balance each round and print it, stopping when it drops below 1. Instead it runs forever. What is the bug?

# Should print: 50.0  25.0  12.5 ... until < 1
balance = 100
while balance >= 1:
    balance = balance / 2
print(balance)
  • A) Change balance >= 1 to balance > 1
  • B) The print(balance) is outside the loop - move it inside so each value is printed
  • C) print(balance) being outside is a separate issue - the real infinite-loop bug is that balance is never updated inside the loop
  • D) The print line needs to be indented to be inside the loop, and the loop condition needs fixing
