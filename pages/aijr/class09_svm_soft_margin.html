What is a Support Vector Machine?

An SVM finds the maximum-margin hyperplane — the decision boundary that is as far as possible from both classes. Only the points closest to the boundary (the support vectors) actually determine where it sits.

Hard vs. Soft Margin

A hard margin (high C) requires every point to be outside the margin — great for clean data, terrible for noise. A soft margin (low C) introduces slack variables ξᵢ ≥ 0 allowing violations, trading a wider margin for a few misclassifications.

Choosing C in Practice

C is a hyperparameter tuned by cross-validation. Low C → high bias, low variance (underfitting). High C → low bias, high variance (overfitting to outliers). The best C balances generalisation vs. training accuracy.
