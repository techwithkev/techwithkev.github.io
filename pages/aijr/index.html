Class 03

Min-Max vs Z-Score Normalizer

A 2D scatter plot of unscaled data (e.g., Age 0-100 vs Income $0-$100k). Buttons apply Min-Max or Z-score scaling, animating the points as they either compress into a strict [0,1] square box or form a zero-centered Gaussian cluster.
Class 03

Why Z-Score Before Gradient Descent

Visualizing how feature scaling transforms the loss landscape from an elongated bowl (causing slow, zigzagging gradient descent) to a circular bowl (enabling fast, direct convergence).
Class 04

K-Fold Carousel

A visual dataset of 100 points. A slider lets students choose k (e.g., 2 through 10). The tool visually highlights the 'Test Fold' rotating through the dataset, showing how average performance is calculated across all folds without data leakage.
Class 04

Overfitting Polynomial

A regression line where students can increase the 'complexity' (polynomial degree). They visually see the line start to memorize the training data while completely missing unseen test points.

The Geometric MSE Square
