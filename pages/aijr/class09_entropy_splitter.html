What is Entropy?

Entropy measures impurity in a node — how mixed up the classes are. A node with 50% red and 50% blue has maximum entropy H = 1.0. A node with only one class has zero entropy H = 0 (perfectly pure).

H(S) = −Σ pᵢ · log₂(pᵢ)

Information Gain

IG measures how much a split reduces entropy. A tree algorithm picks the split with the highest IG — the cut that makes the children as pure as possible.

IG = H(parent) − Σ (|Lᵢ|/|S|)·H(Lᵢ)

SVMs vs Trees

Decision Trees split data axis-aligned (horizontal or vertical cuts), greedily maximising IG. SVMs instead find the maximum-margin hyperplane that separates classes — often a diagonal line, tolerating no axis-alignment constraint.
