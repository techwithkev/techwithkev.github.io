Contiguous Memory

                

                    Under the hood, computer memory is strictly one-dimensional. 
                    Whether an image is a 2D matrix or a 3D tensor, all elements are stored next to each other in a flat contiguous block of memory.
                

                

                    Reshaping an array does not change the data in memory. It only changes the metadata (the strides and shape) that dictates how code navigates through it.
                

            


            
            

                
02

                
The Reshaping Index Math

                

                    To transition a flat index $i$ into a matrix of columns $W$, the new coordinates are computed as:
                    

                    Row = Math.floor(i / W)
                    

                    Col = i % W
                

                

                    Tensors in 3D introduce a depth/layer layer size $H \times W$. The index floats through layers, then rows, then columns. Try tracking individual block indices as they fold!
                

            


            
            

                
03

                
From Shapes to AI

                

                    Machine learning is entirely built on reshaping arrays. 
                    For example, to feed an image into a Dense Layer, we must **flatten** a $(28, 28)$ matrix into a $(784,)$ flat vector.
                

                

                    In Transformers, inputs are continually restructured between shapes like `(Batch, Sequence, Head, Dimension)` to let different attention channels read data parallelly.
